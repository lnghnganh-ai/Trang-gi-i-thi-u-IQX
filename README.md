# IQX · Trang giới thiệu (bản demo)

Bản demo đề xuất thiết kế lại trang giới thiệu của IQX (iqx.vn).

## Xem trang

Khi bật GitHub Pages (nhánh `main`, thư mục gốc), trang có tại:
https://lnghnganh-ai.github.io/Trang-gi-i-thi-u-IQX/

## Cấu trúc

- `index.html` tự chuyển sang `IQX-gioi-thieu.html` để link GitHub Pages gọn.

- `IQX-gioi-thieu.html` là bản đóng gói một file, đã nhúng sẵn mọi hình ảnh. Tải về rồi mở bằng trình duyệt là xem được.
- `gioi-thieu/index.html` là mã nguồn để chỉnh sửa.
- `gioi-thieu/assets/` chứa logo, linh thú và tranh phong cảnh lấy từ iqx.vn.

## Ghi chú nội dung

- Giá trong bảng điện, lịch sự kiện và mô phỏng Flashback (VN-Index 2022) là dữ liệu minh họa và đã được ghi nhãn trên trang.
- Quyền lợi gói Premium và lộ trình từ 2027 là đề xuất, cần IQX xác nhận trước khi công bố.
